# FLOW-STANDOFF

Aplicativo Android independente com painel de treinamento visual.

## Recursos
- Alternância de marcadores demonstrativos (ESP Demo).
- Alternância do treinador de mira.
- Seleção entre alvo de treino "Cabeça" e "Peito".
- Contador de acertos por toque.

## Compilar no Android
Abra o repositório no AndroidIDE ou em outro ambiente Android com suporte a Gradle, sincronize o projeto e gere o APK de depuração.

## Limites do projeto
O aplicativo não lê a memória do Standoff 2, não identifica adversários reais e não controla a mira dentro do jogo. Os marcadores e o alvo existem somente nesta tela de treinamento.

## Requisitos
- JDK 17
- Android SDK 35
- Gradle compatível com Android Gradle Plugin 8.7.3
